# Plan — 2026-04-26 Auth FE UI

## Context

The backend Google SSO auth is fully implemented. The frontend has NextAuth v5 wired up (Google provider, backend sync callback, route protection middleware) but all three pages are unstyled placeholders. This plan adds Tailwind CSS + shadcn/ui and builds proper UI for the home, login, and dashboard pages.

## Scope

- Install Tailwind CSS and shadcn/ui
- Home page: hero section + "Get Started" / "Sign In" button
- Login page: centred card with Google SSO button
- Dashboard page: simple welcome card + sign-out button
- Mobile-first responsive layout on all pages
- No backend changes

## Out of scope

- Any new routes beyond `/`, `/login`, `/dashboard`
- User profile editing
- Dark mode toggle

---

## Implementation Steps

### 1. Install Tailwind CSS

```bash
cd frontend
npm install tailwindcss @tailwindcss/postcss postcss
```

Create `frontend/postcss.config.mjs`:

```js
const config = { plugins: { '@tailwindcss/postcss': {} } };
export default config;
```

Create `frontend/src/app/globals.css`:

```css
@import 'tailwindcss';
```

Import globals in `frontend/src/app/layout.tsx`:

```ts
import './globals.css';
```

### 2. Install shadcn/ui

```bash
npx shadcn@latest init
```

Init answers: TypeScript yes, style Default, base colour Slate, global CSS `src/app/globals.css`, CSS variables yes, tailwind config `tailwind.config.ts`, components alias `@/components`, utils alias `@/lib/utils`, RSC yes, no Turbopack.

Add components needed:

```bash
npx shadcn@latest add button card
```

This installs:

- `frontend/src/components/ui/button.tsx`
- `frontend/src/components/ui/card.tsx`
- `frontend/src/lib/utils.ts` (`cn` helper)

### 3. Home page — `frontend/src/app/page.tsx`

Server component. Shows a centred hero with app name, tagline, and a "Sign in with Google" link that routes to `/login`.

Layout (mobile-first):

```
┌─────────────────────────┐
│                         │
│        Kendara          │  ← text-4xl font-bold
│   Your cosmic guide     │  ← text-muted-foreground
│                         │
│  [ Sign in with Google ]│  ← Button asChild → Link href="/login"
│                         │
└─────────────────────────┘
```

### 4. Login page — `frontend/src/app/login/page.tsx`

Client component (`'use client'`). Centred card with Google SVG icon + button. Calls `signIn('google', { callbackUrl: '/dashboard' })` on click.

Layout:

```
┌─────────────────────────┐
│  Card                   │
│  ┌───────────────────┐  │
│  │ Kendara           │  │  ← CardTitle
│  │ Sign in to cont.. │  │  ← CardDescription
│  │                   │  │
│  │ [G Continue with  │  │  ← Button variant="outline" w-full
│  │     Google]       │  │
│  └───────────────────┘  │
└─────────────────────────┘
```

### 5. Dashboard page — `frontend/src/app/dashboard/page.tsx`

Server component. Uses `await auth()` (already present), redirects if no session. Shows welcome card with user avatar (if present), name, email, and a `SignOutButton` client component.

`SignOutButton` → small `'use client'` component in `frontend/src/components/SignOutButton.tsx` that calls `signOut({ callbackUrl: '/' })`.

Layout:

```
┌──────────────────────────────┐
│ Header: Kendara        [Nav] │
├──────────────────────────────┤
│                              │
│  Card                        │
│  ┌────────────────────────┐  │
│  │ 👤  Welcome, {name}   │  │
│  │     {email}           │  │
│  │            [Sign out] │  │
│  └────────────────────────┘  │
│                              │
└──────────────────────────────┘
```

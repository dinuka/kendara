# Plan — Google SSO Auth (NextAuth v5 + MongoDB native driver)

## Context

Adding Google SSO to the Kendara monorepo. FE uses NextAuth v5 (HTTP-only cookie sessions). Backend owns MongoDB persistence via repository pattern + MVC — no ORM, raw MongoDB driver queries only. The FE's NextAuth `signIn` callback syncs users to the backend; backend only verifies Google ID tokens, never touches OAuth.

├── repos/

└── index.ts                 bootstrap + global error handler

**Dependency injection flow in `index.ts`:**

```
connectClient() → db
  → new UserRepo(db)
    → new AuthController(userRepo)
      → makeAuthRouter(authController)
        → app.use('/api/auth', router)
```

Each layer receives its dependency via constructor — no DI framework, no interface, just plain constructor injection.

  Forbidden = 'FORBIDDEN',
  NotFound = 'NOT_FOUND',

  status: number;
  code: ErrorCodes;
  message: string;

export const badRequest = (message = 'Bad request'): AppError =>
  ({ status: 400, code: ErrorCodes.BadRequest, message });

export const forbidden = (message = 'Forbidden'): AppError =>
  ({ status: 403, code: ErrorCodes.Forbidden, message });

export const notFound = (message = 'Not found'): AppError =>
  ({ status: 404, code: ErrorCodes.NotFound, message });

### Schema generation (manual CLI — run from `backend/`)

Run whenever a request/response type changes, then commit the updated JSON:

```bash
npx typescript-json-schema tsconfig.schema.json SyncUserBody --required --strictNullChecks --noExtraProps --out src/schemas/auth/syncUserBody.json
npx typescript-json-schema tsconfig.schema.json SyncUserData --required --strictNullChecks --out src/schemas/auth/syncUserData.json
```

- `--required` — marks all non-optional fields as required in the schema
- `--strictNullChecks` — honours the project's `strict: true`
- `--noExtraProps` on request only — rejects unknown fields from clients; omitted on response since MongoDB documents may include `_id`
- Generated `.json` files are committed to git — they are source artifacts required for `tsc` to compile the JSON imports

### `backend/src/lib/validate.ts`

```typescript
import Ajv, { ValidateFunction } from 'ajv';
import addFormats from 'ajv-formats';
import { JSONSchema7 } from 'json-schema';
import { badRequest, internalServerError } from '../errors';

const ajv = new Ajv({ allErrors: true });
addFormats(ajv);

const buildValidator = <T>(schema: JSONSchema7, onError: (msg: string) => never) => {
  const validate: ValidateFunction = ajv.compile(schema);
  return (data: unknown): T => {
    if (validate(data)) return data as T;
    const message = validate.errors
      ?.map((e) => `${e.instancePath || 'body'} ${e.message}`)
      .join('; ') ?? 'Validation failed';
    onError(message);
  };
};

export const compileValidator = <T>(schema: JSONSchema7) =>
  buildValidator<T>(schema, (msg) => { throw badRequest(msg); });

export const compileResponseValidator = <T>(schema: JSONSchema7) =>
  buildValidator<T>(schema, (msg) => { throw internalServerError(msg); });
```

- AJV instance created once at module load — `compile()` is expensive, called once per validator at startup
- `compileValidator` — request body failures → 400
- `compileResponseValidator` — response data failures → 500 (our own code returned bad data)

### `backend/src/repos/UserRepo.ts`

```typescript
import { Db } from 'mongodb';
import User, { Role } from '../models/User';

const COLLECTION = 'users';

export default class UserRepo {
  constructor(private readonly db: Db) {}

  async upsertByGoogleId(
    googleId: string,
    email: string,
    name: string,
    avatarUrl?: string,
  ): Promise<User> {
    const now = new Date();
    const result = await this.db.collection<User>(COLLECTION).findOneAndUpdate(
      { googleId },
      {
        $set: { email, name, avatarUrl, updatedAt: now },
        $setOnInsert: { id: crypto.randomUUID(), googleId, role: Role.User, createdAt: now },
      },
      { upsert: true, returnDocument: 'after' }
    );
    return result!;
  }

  async findByGoogleId(googleId: string): Promise<User | undefined> {
    return await this.db.collection<User>(COLLECTION).findOne({ googleId }) ?? undefined;
  }
}
```

- Flat positional params — no input object wrapper
- `avatarUrl` is optional (`?`) not `string | undefined`
- Custom `id` via `crypto.randomUUID()` in `$setOnInsert` — no `ObjectId`

### `backend/src/controllers/AuthController.ts`

```typescript
import { OAuth2Client } from 'google-auth-library';
import UserRepo from '../repos/UserRepo';
import { config } from '../config/config';
import { forbidden } from '../errors';
import { SyncUserRequest } from '../types/auth/syncUserRequest';
import { SyncUserResponse } from '../types/auth/syncUserResponse';

export default class AuthController {
  private readonly client = new OAuth2Client(config.googleClientId);

  constructor(private readonly userRepo: UserRepo) {}

  async syncUser({ body: { idToken } }: SyncUserRequest): Promise<SyncUserResponse> {
    const ticket = await this.client.verifyIdToken({ idToken, audience: config.googleClientId });
    const payload = ticket.getPayload();

    if (!payload?.sub) {
      throw forbidden('Invalid Google token');
    }

    const { sub: googleId, email = '', name = '', picture: avatarUrl } = payload;
    const user = await this.userRepo.upsertByGoogleId(googleId, email, name, avatarUrl);

    return { status: 200, data: { user } };
  }
}
```

- No `!idToken` guard — the route validates `idToken` presence/type before the controller is called
- Throws `forbidden` if Google token is invalid — no return-based error path
- No `AuthUser` parameter — `syncUser` is a public (unauthenticated) endpoint

### `backend/src/routes/authRoutes.ts`

```typescript
import { Router, Request, Response, NextFunction } from 'express';
import AuthController from '../controllers/AuthController';
import { AppError } from '../errors';
import { compileValidator, compileResponseValidator } from '../lib/validate';
import { SyncUserBody } from '../types/auth/syncUserRequest';
import { SyncUserData } from '../types/auth/syncUserResponse';
import syncUserBodySchema from '../schemas/auth/syncUserBody.json';
import syncUserDataSchema from '../schemas/auth/syncUserData.json';

// Compiled once at module load (startup) — not per-request
const validateSyncUserBody = compileValidator<SyncUserBody>(syncUserBodySchema);
const validateSyncUserData = compileResponseValidator<SyncUserData>(syncUserDataSchema);

export const makeAuthRouter = (controller: AuthController): Router => {
  const router = Router();

  router.post('/sync', async (req: Request, res: Response, next: NextFunction) => {
    try {
      const body = validateSyncUserBody(req.body);         // throws 400 on failure

      const result = await controller.syncUser({
        params: req.params as Record<string, string>,
        query: req.query as Record<string, string>,
        body,
      });

      if (result.data !== undefined) {
        // Coerce Dates → strings (same as res.json() does) before validating wire shape
        validateSyncUserData(JSON.parse(JSON.stringify(result.data)));  // throws 500 on failure
      }

      res.status(result.status).json({ data: result.data });
    } catch (err) {
      if ((err as AppError).code !== undefined) {
        const appErr = err as AppError;
        res.status(appErr.status).json({ error: { code: appErr.code, message: appErr.message } });
      } else {
        next(err);
      }
    }
  });

  return router;
};
```

- Request body validated before controller call — `idToken` presence/type enforced at runtime
- Response data coerced via `JSON.parse(JSON.stringify(...))` before validation so `Date` objects become strings (matching the `@format date` schema)
- Validators compiled once at module scope

### `backend/src/index.ts`

```typescript
import 'dotenv/config';
import express, { Request, Response, NextFunction } from 'express';
import cors from 'cors';
import { config } from './config/config';
import { connectClient } from './config/db';
import UserRepo from './repos/UserRepo';
import AuthController from './controllers/AuthController';
import { makeAuthRouter } from './routes/authRoutes';
import { internalServerError } from './errors';

const app = express();

app.use(cors({ origin: config.frontendUrl, credentials: true }));
app.use(express.json());

app.get('/api/health', (_req: Request, res: Response) => {
  res.json({ status: 'ok', timestamp: new Date().toISOString() });
});

connectClient(config.mongoUri, config.mongoDbName).then((db) => {
  const userRepo = new UserRepo(db);
  const authController = new AuthController(userRepo);
  app.use('/api/auth', makeAuthRouter(authController));

  // Global error handler — catches unknown errors forwarded via next(err)
  app.use((_err: unknown, _req: Request, res: Response, _next: NextFunction) => {
    const err = internalServerError();
    res.status(err.status).json({ error: { code: err.code, message: err.message } });
  });

  app.listen(config.port, () =>
    console.log(`[backend] Server running on http://localhost:${config.port}`)
  );
});
```

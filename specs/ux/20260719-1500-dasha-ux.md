## 1. Overview

The Dasha Periods feature renders the Vimshottari Dasha timeline — a hierarchical view of planetary periods governing the native's life. It provides a nested accordion interface with five levels (Mahadasha, Antardasha, Vidasa, Sukshama, Prana), auto-expands the currently active period chain, and allows free exploration of past and future periods. All dasha data is pre-calculated server-side at horoscope creation time; the client performs only date comparison to determine the active period.

---

## 2. User Flow: View Dasha Timeline

```
User opens Horoscope Detail page →
    1. Navigates to the Dashas tab (via tab bar: Charts | Calculations | Dashas | Metadata)
    2. Dasha section loads: summary bar + nested accordion timeline
    3. Client computes current date, walks the dasha array to find the active period at each level
    4. Summary bar renders: "Current Period: Jupiter Mahadasha > Venus Antardasha > Moon Vidasa"
       — each level is a clickable pill badge
    5. Mahadasha list renders with the active Mahadasha auto-expanded:
         - Active Mahadasha shows left-border accent (Indigo #6366F1)
         - Active Mahadasha shows "Active" pill badge
         - Active Mahadasha is expanded → reveals its Antardasha list
         - Within that, the active Antardasha is auto-expanded → reveals Vidasa list
         - Within that, the active Vidasa is auto-expanded → reveals Sukshama list
         - Within that, the active Sukshama is auto-expanded → reveals Prana rows (if any)
    6. All non-active periods at every level remain collapsed by default
    7. User clicks a Mahadasha header to expand/collapse its Antardasha periods
    8. User clicks an Antardasha header to expand/collapse its Vidasa periods
    9. User clicks a Current Period pill badge → page scrolls to that period's position
    10. User explores past and future periods by expanding/collapsing at will
    11. Smooth CSS animations on every expand/collapse toggle
```

## 4. Accordion Component Design

### Visual Hierarchy by Level

| Level | Indentation | Font Size | Opacity | Border | Background |
|-------|-------------|-----------|---------|--------|------------|
| Mahadasha | 0 (root) | 14px `--text-primary` | 100% | 1px `--border` | `--surface` |
| Antardasha | 16px | 13.5px `--text-primary` | 95% | 1px `--border` (lighter) | `--surface-elevated` |
| Vidasa | 32px | 13px `--text-primary` | 90% | 1px `--border` (lighter) | `--surface` |
| Sukshama | 48px | 12.5px `--text-primary` | 85% | none (only divider) | `--surface-elevated` |
| Prana | 64px | 12px `--text-secondary` | 80% | none | none |

### Mahadasha Row

```
┌────────────────────────────────────────────────────────────────────┐
│  ▸ ♃ Jupiter Mahadasha    1990 Jan 15 — 1996 Jan 15    6 years   │
│  [Active]                                             [Chevron ▸]│
└────────────────────────────────────────────────────────────────────┘
```

| Element | Details |
|---------|---------|
| Planet glyph | Unicode astrological symbol (e.g., ♃ for Jupiter), 16px, `--text-primary` |
| Planet name | Localized name: "Jupiter" or "ගුරු" |
| Level label | "Mahadasha" / "මහා දශා" in `--text-secondary`, 11px |
| Date range | "1990 Jan 15 — 1996 Jan 15", 12px `--text-secondary` |
| Duration | "6 years", 12px `--text-secondary`, right-aligned |
| Active badge | Small pill (16px tall) with "Active" text, `--primary` bg, white text — only if active |
| Chevron | 16x16px icon, rotates 180° on expand, 200ms `ease-in-out` |
| Left border active | 3px solid `--primary` on the left edge when active |
| Background active | `--primary` at 5% opacity tint when active |

```
┌────────────────────────────────────────────────────────────────────┐

│                 [Active]                      3 days  [Chevron ▸] │

```

- Indented 48px from the left edge
- No bottom border — only subtle horizontal divider between siblings
- If no sub-periods (empty sukshama array), the row is a leaf node (no chevron, not expandable)

### Prana Row

```
┌────────────────────────────────────────────────────────────────────┐
│                        ● ☿ Mercury Prana                          │
│                        1990 Jan 15 12:00 — 1990 Jan 16 00:00      │
│                        12 hours                                    │
└────────────────────────────────────────────────────────────────────┘
```

- Indented 64px from the left edge
- No chevron — Prana is always a leaf (no sub-periods)
- Uses a small dot (●) instead of chevron as the prefix indicator
- Date format includes time: "1990 Jan 15 12:00"
- Duration: "12 hours"
- Even lighter visual weight — `--text-secondary` color
- No border on the row item

### Expand/Collapse Behavior

- **Chevron**: Points right (▸) when collapsed, rotates 180° to point down (▾) when expanded
- **Animation**: CSS `transform: rotate()` on the chevron, 200ms `ease-in-out`
- **Body animation**: `max-height` transition from 0 to `--content-height`, 300ms `ease-in-out`
- **Body overflow**: `overflow: hidden` during transition
- **Body content**: Rendered in DOM at all times (not conditional), hidden via `max-height: 0` and `overflow: hidden` when collapsed — this ensures smooth animation
- **React.memo**: Each accordion component wrapped in `React.memo` to prevent re-render of siblings when one is toggled
- **Stagger**: Collapse animations may be staggered with 50ms delay per level to prevent layout thrashing

### Layout

```

│  ● Current:                                                    │
│  [♃ Jupiter Mahadasha]  >  [♀ Venus Antardasha]  >            │

### Badge Design

| Element | Details |
|---------|---------|
| Label | "● Current:" / "● වත්මන්:" in `--text-secondary`, 12px |
| Pill shape | `border-radius: 9999px`, 6px horizontal padding, 2px vertical padding |
| MD pill | `--primary` background at 15% opacity, `--primary` text, 12px font |
| AD pill | Same style but slightly reduced opacity |
| VD/SK pill | Lighter tint, `--primary` at 10% opacity |
| Separator | ">" character in `--text-secondary`, 11px |
| Date line | Below the badge row, shows the active Mahadasha date range in 11px `--text-secondary` |
| Click behavior | Clicking a badge scrolls to that period in the accordion via `scrollIntoView({ behavior: 'smooth', block: 'start' })` |
| Highlight | On scroll-to, the target period gets a brief flash highlight (200ms primary background flash) |

### Edge Cases

- **Not in any Vidasa**: Badge chain shows only MD > AD, with "(not in Vidasa)" muted text
- **Not in Sukshama**: Chain shows MD > AD > VD, with "(not in Sukshama)"
- **All periods passed**: No current period badge shown; summary bar shows "All periods completed" / "සියලුම කාල පරිච්ඡේද අවසන්"
- **No periods started yet** (birth in future, edge case): "Periods begin on [birth date]"

## 6. Visual States

### Accordion Header

| State | Visual |
|-------|--------|
| **Default (collapsed)** | Chevron points right (▸), no background tint, standard border |
| **Expanded** | Chevron points down (▾), subtle background change (1% darker), bottom border radius removed (body attaches flush) |
| **Active (current period)** | 3px left border accent in `--primary`, 5% `--primary` background tint, "Active" pill badge |
| **Hover** | 2% background darkening, cursor pointer, 100ms transition |
| **Focus** | Visible 2px `--primary` focus ring with 2px offset, `outline: none`, `ring-2 ring-indigo-500` |
| **Disabled** | N/A — all periods are always interactive |

### Active Period Highlighting

The active period is visually distinguished in three ways (never rely on color alone):

1. **Left border accent**: 3px solid `--primary` (`#6366F1`) on the left edge
2. **Background tint**: `--primary` at 5% opacity background fill
3. **"Active" text badge**: Small pill with "● Active" text

### Active Period Chain vs. Ancestor Highlighting

Only the **direct active chain** gets highlighting. Non-active ancestors of active periods remain in default style (not highlighted). For example, if Jupiter Mahadasha is active but a particular Antardasha within it is not, only that active Antardasha gets highlighted — all other Antardasha siblings under Jupiter appear in default style.

## 7. Keyboard Navigation

The dasha accordion implements the tree view keyboard navigation pattern per WAI-ARIA Tree View design pattern:

| Key | Action |
|-----|--------|
| `Tab` | Moves focus into the tree and through focusable elements outside the tree. Tab enters the tree at the first visible treeitem. Shift+Tab exits the tree from the last visible treeitem. |
| `Enter` / `Space` | If the focused item is collapsed, expands it. If expanded, collapses it. |
| `Up Arrow` | Moves focus to the previous visible treeitem at the same level. If at the first item, wraps to the last. |
| `Down Arrow` | Moves focus to the next visible treeitem at the same level. If at the last item, wraps to the first. |
| `Left Arrow` | If the focused item is expanded, collapses it. If collapsed, moves focus to its parent treeitem. |
| `Right Arrow` | If the focused item is collapsed and has children, expands it and moves focus to the first child. If already expanded, moves focus to the first child. |
| `Escape` | Collapses the deepest expanded level in the focus path (not the entire tree). |
| `Home` | Moves focus to the first visible treeitem at the root level. |
| `End` | Moves focus to the last visible treeitem at the root level. |
| `*` (asterisk) | Expands all treeitems at the current level (future enhancement). |

### Focus Management

- When expanding a treeitem, focus stays on the expanded item (the header) — it does NOT move into the children
- When collapsing, focus stays on the collapsed item
- When closing the deepest expanded level via Escape, focus moves up one level to the parent
- When tabbing into the tree for the first time, focus lands on the first visible root-level treeitem (the first Mahadasha)
- Visible focus indicator: 2px `--primary` ring with 2px offset

```

### Mobile Depth Capping

On screens < 640px, the visible depth is **capped at 3 levels** (Mahadasha, Antardasha, Vidasa). Sukshama and Prana periods are not rendered inline. Instead:

1. When a user taps a Vidasa row that has Sukshama children, a **slide-up sheet** (bottom drawer) opens
2. The sheet shows the Sukshama (and Prana) details for that Vidasa in a flat scrollable list
3. The sheet has a drag handle at the top, title showing the parent period, and a close button
4. Sheet height: 50% of viewport (expandable to 85%)
5. Inside the sheet, each Sukshama row shows: planet name, date range, duration, and any Prana sub-rows
6. Tap outside the sheet or swipe down to dismiss

### Two-Column Mode

On tablet (≥ 768px but < 1024px), an optional two-column layout can be used:

- **Left column** (60%): The nested accordion timeline
- **Right column** (40%): Detail view of the currently selected/active period

The right column shows:

- Planet lord name and glyph (large, 20px)
- Full date range with duration
- A compact list of all sub-periods within this period (flat list, no accordion)
- Active period indicator
- Clicking a different period in the left column updates the right column

Two-column mode is **not the default** — users can toggle it via a small button (□/⊞) at the top right of the timeline section. Default on tablet is single-column (same as desktop).

### Focus Management

- **Tab entry**: First Tab into the dashboard section focuses the first visible treeitem (first Mahadasha in the list)
- **Expanding**: Focus stays on the expanded treeitem header (does not move into children)
- **Collapsing**: Focus stays on the collapsed treeitem
- **Escape**: Focus moves up one level to the parent treeitem
- **Current period badge click**: Focus moves to the target period treeitem in the accordion
- **Tab exit**: Shift+Tab from the first treeitem exits the tree; Tab from the last treeitem exits the tree

### Color Independence

Active period highlighting does **not** rely solely on color. Three indicators:

1. Left border accent (3px `--primary`)
2. Background tint (5% `--primary`)
3. Text label: "● Active" with `aria-label="Active period"`

This ensures users with color vision deficiencies can identify the active period.

### Focus Indicator

- All interactive elements have a visible 2px `--primary` (`#6366F1`) focus ring
- Focus ring has 2px offset from the element edge
- `outline: none` on focus, replaced by `box-shadow: 0 0 0 2px var(--primary)` for consistency
- On mobile, focus ring is replaced by `outline: 2px solid var(--primary)` (more visible on touch)

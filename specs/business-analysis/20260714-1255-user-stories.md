# User Stories

## Authentication

### US-001: Google SSO Login
- **Title**: Student logs in via Google SSO
- **Description**: As a student, I want to log in using my Google account so that I can access the system securely without managing another password.
- **Acceptance Criteria**:
  - User clicks "Login with Google" button
  - Google OAuth flow completes successfully
  - System automatically assigns Student role
  - User is redirected to the dashboard
  - If user is a Super Admin, appropriate admin privileges are granted
- **Priority**: High
- **Actor**: Student, Super Admin

## Add Horoscope

### US-002: Input Birth Details
- **Title**: Student adds a new horoscope with birth details
- **Description**: As a student, I want to input a person's birth details so that the system can calculate their horoscope.
- **Acceptance Criteria**:
  - Form accepts: Name, Birth date & time, Location (auto-geocoded), Latitude/Longitude (manual), Gender, Ayanamsha (default Lahiri)
  - Location input auto-suggests and geocodes to Lat/Lon
  - Lat/Lon fields are auto-populated from the location name
  - User can manually edit Lat/Lon values after auto-population
  - Ayanamsha dropdown includes Lahiri as default plus other options
  - All required fields validated before submission
- **Priority**: High
- **Actor**: Student

### US-003: Horoscope Calculation
- **Title**: System calculates horoscope details from birth data
- **Description**: As a system, I want to calculate all horoscope details from the submitted birth data so that the student can analyze them.
- **Acceptance Criteria**:
  - Calculates Ascendant/Rising Sign with degree
  - Calculates House (Bhava) details: start, middle, end for each house
  - Calculates Planet (Graha) positions in signs and houses
  - Calculates Nakshatra and Pada/Quarter
  - Calculates Mahadasha, Antardasha/Bhukti periods
  - All calculations use offline libraries (no external API calls)
- **Priority**: High
- **Actor**: System

### US-004: Advanced Calculations
- **Title**: System calculates advanced astrological values
- **Description**: As a system, I want to calculate advanced astrological values from the base horoscope data so that students get comprehensive analysis.
- **Acceptance Criteria**:
  - Calculates Planetary Strength (Uchcha, Neecha, Shatru, etc.)
  - Calculates Planetary Aspects with degree
  - Identifies Lord of 22nd Drekkana
  - Identifies Lord of 64th Navamsa
  - Identifies Badhaka Planet / Badhakesh
  - Identifies Maraka Planets
  - Identifies Atmakaraka Planet
  - Identifies Yogas
  - Identifies Doshas
- **Priority**: High
- **Actor**: System

### US-005: Chart Generation
- **Title**: System generates astrological charts
- **Description**: As a system, I want to generate all astrological charts from calculated data so that the student can visualize the horoscope.
- **Acceptance Criteria**:
  - Generates Birth Chart (Rasi Chart)
  - Generates House Chart (Bhava Chart)
  - Generates Navamsa (D9 Chart)
  - Generates Drekkana (D3 Chart)
  - Generates Dasamsa (D10 Chart)
  - Generates Shodasha Vargas / Divisional Charts
  - Generates Chandra Lagna (Moon Ascendant) chart
  - Generates Surya Lagna (Solar Ascendant) chart
  - All charts are rendered in a clear visual format
- **Priority**: High
- **Actor**: System

### US-006: Horoscope Privacy Settings
- **Title**: Student marks horoscope as public or private
- **Description**: As a student, I want to mark my horoscope as public or private and choose whether to show the name so that I can control visibility.
- **Acceptance Criteria**:
  - Toggle between public/private visibility
  - Option to show or hide the person's name on public horoscopes
  - Privacy setting can be changed anytime
  - Public horoscopes visible to other students in search
- **Priority**: Medium
- **Actor**: Student

## Search Horoscope

### US-007: Basic Horoscope Search (RAG-Based)
- **Title**: Student searches horoscopes with basic filters via RAG
- **Description**: As a student, I want to search horoscopes using basic astrological filters powered by a RAG pipeline so that I can find relevant study material using natural language.
- **Acceptance Criteria**:
  - Search shows own horoscopes and public horoscopes
  - Horoscope data is indexed as vector embeddings
  - Search queries are converted to embeddings via RAG pipeline
  - Can filter by simple astrological phrases (e.g., "මේෂ ලග්නය" for Aries Ascendant)
  - Can filter by planetary conditions (e.g., "ශනි උච්ච" for Saturn exaltation)
  - Can filter by planet in house (e.g., "ගුරු 3" for Jupiter in 3rd house)
  - Results are ranked by relevance via semantic similarity
  - Handles both Sinhala and English search terms
- **Priority**: High
- **Actor**: Student

### US-008: Complex Search (RAG-Based)
- **Title**: Student performs complex multi-condition searches via RAG
- **Description**: As a student, I want to combine multiple astrological conditions in a single natural language search powered by a RAG pipeline so that I can find horoscopes matching complex criteria.
- **Acceptance Criteria**:
  - Understands compound queries like "මේෂ ලග්නයේ ශනි උච්චව ගුරු 3 භාවයේ ඇති ගුරුට සුබ දෘෂ්ඨි නොවැටෙන"
  - Understands yoga-based queries like "පරිවර්තන යෝග තිබෙන"
  - Understands career-related queries like "රැකියාව ගුරු වෘත්තිය විය හැකි"
  - Queries are converted to embeddings via RAG pipeline
  - Retrieves matching horoscopes based on semantic similarity
  - Returns accurate results matching all conditions
  - Supports both Sinhala and English
- **Priority**: High
- **Actor**: Student

### US-009: Configurable Results Display
- **Title**: Student configures which sections to display
- **Description**: As a student, I want to hide or show specific calculation sections and charts in the search results so that I can focus on what matters for my study.
- **Acceptance Criteria**:
  - Configuration panel to toggle sections on/off
  - Sections include: charts (individual types), calculations, strengths, aspects, etc.
  - Configuration is persisted per user
  - Changes apply immediately to results view
- **Priority**: Medium
- **Actor**: Student

## Update Metadata

### US-010: Add Labels and Tags
- **Title**: Student adds metadata labels to horoscopes
- **Description**: As a student, I want to add labels, tags, and metadata to horoscopes (including public ones) so that I can organize and categorize them for my studies.
- **Acceptance Criteria**:
  - Can add key-value metadata to own horoscopes
  - Can add key-value metadata to public horoscopes (personal copy)
  - Metadata examples: job, children count, skills, etc.
  - Can toggle metadata visibility (public/private)
  - Can remove calculated yogas if incorrect
  - Metadata changes are saved and persisted
- **Priority**: Medium
- **Actor**: Student

## Share Horoscope

### US-011: Generate Share Link
- **Title**: Student generates temporary share link for private horoscope
- **Description**: As a student, I want to generate a temporary share link for my private horoscope so that I can share it with specific people.
- **Acceptance Criteria**:
  - Generate unique share link for any own horoscope
  - Link has configurable expiration time
  - Only people with the link can access the horoscope
  - Link can be revoked/cancelled anytime
- **Priority**: Medium
- **Actor**: Student

### US-012: Download Horoscope
- **Title**: Student downloads horoscope as PDF or image
- **Description**: As a student, I want to download horoscope details and charts as PDF or image so that I can save or print them.
- **Acceptance Criteria**:
  - Download as PDF option includes all visible sections
  - Download as image option for charts
  - Downloaded file is properly formatted
  - Works for own and public horoscopes
- **Priority**: Medium
- **Actor**: Student

## Super Admin

### US-013: Admin Dashboard
- **Title**: Super Admin manages all horoscopes and users
- **Description**: As a super admin, I want to view, update, and delete horoscopes and manage users so that I can maintain the system.
- **Acceptance Criteria**:
  - Can see all horoscopes (public and private)
  - Can update any horoscope
  - Can delete public horoscopes
  - Can manage users (activate/deactivate/role change)
  - Admin actions are logged
- **Priority**: Medium
- **Actor**: Super Admin

## Internationalization

### US-014: Language Support
- **Title**: System supports Sinhala and English
- **Description**: As a student, I want to use the system in Sinhala or English so that I can study in my preferred language.
- **Acceptance Criteria**:
  - UI text available in both Sinhala and English
  - Search supports both Sinhala and English terms
  - Astrological terms translated accurately
  - Language can be switched at any time
  - Preference is remembered across sessions
- **Priority**: High
- **Actor**: Student

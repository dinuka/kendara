# පුෂ්කර

Need to use sign's number for this as in ZODIAC_SIGN_LABELS_SI.

1, 5, 9 => 7, 9
2, 6, 10, 3, 7, 11 => 2, 12
4, 8, 12 => 4, 6

Need to use above logic for find Pushkara planets.

If some planet in 1 - Mesha, 5 - සිංහ, 9 - ධනු then need to check 7 - තුලා and 9 - ධනු sign in the Navansaka chart. If that planet in the that houses in Navansaka chart it should a Pushkara planets.

As example, Budha in the මකර rashi. Then need to check වෘශභ and මීන sign's houses in the navansaka chart. If the Budha in one of වෘශභ or මීන then Budha can mark as the Pushkara.

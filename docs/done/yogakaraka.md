# යෝගකාරක

- Need to show in the planets table in other column.
- In Vedic astrology (Jyotisha), a Yogakāraka (යෝගකාරක ග්‍රහයා) is a planet that simultaneously owns a Kendra (1, 4, 7, 10) house and a Trikona (1, 5, 9) house.
- How to calculate.
  - Check planets owning for Kendra (4, 7, 10) and Trikona (5, 9). (1st house should exclude.)
  - If some planet in any Kendra and any Trikon then that planet can mark as the Yogakaraka.
  - If some planet owning 4/5, 4/9, 7/5, 7/9, 10/5, or 10/9 then that planet can makr as the yogakara.

- Examples
  
  - Taurus Lagna

    1st = Taurus → Venus
    5th = Virgo → Mercury
    9th = Capricorn → Saturn
    10th = Aquarius → Saturn

  So Saturn owns the 9th + 10th:

  9th (Trikona) + 10th (Kendra) → Saturn is Yogakaraka.

  - Libra Lagna

  4th = Capricorn → Saturn
  5th = Aquarius → Saturn

  So Saturn owns the 4th + 5th:

  4th (Kendra) + 5th (Trikona) → Saturn is Yogakaraka.

  - Cancer Lagna

  5th = Scorpio → Mars
  10th = Aries → Mars

  So Mars owns the 5th + 10th:

  5th (Trikona) + 10th (Kendra) → Mars is Yogakaraka.

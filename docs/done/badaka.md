# බාධක ග්‍රහයන්

- මට්ටම් 4ක බාධක ග්‍රහයන් ඇත. ඔවුන්ව `බාධක(මට්ටම)්‍ර` ලෙසින් ග්‍රහ වගුවේ වෙනත් පෙල යටතේ පෙන්විය යුතුය. උදාහරණයක් ලෙස කුජ 3වන මට්ටමේ බාධක ග්‍රහයෙක් නම් කුජට අදාල තීරුවේ `බාධක(3)` ලෙසින් පෙන්විය යුතුය.

## බාධක ග්‍රහයන් සොයනා හැටි

චර රාශී සදහා - 11 බාධක වේ.
තිර රාශී සදහා - 9 බාධක වේ.
උභය රාශී සදහා - 7 බාධක වේ.

පළවන මට්ටමේ බාධකයන් - බාධක රාශියේ ඇති ග්‍රහයන්ට අදාල නැකත් වල සිටින ග්‍රහයන්
දෙවන මට්ටමේ බාධකයන් - බාධක රාශියේ සිිටින ග්‍රහයන්
තෙවන මට්ටමේ බාධකයන් - බාධක ස්ථාන අධිපතිගේ නැකත් වල සිටින ග්‍රහයන්
හතරවන මට්ටමේ බාධකයා - බාධක ස්ථාන අධිපති

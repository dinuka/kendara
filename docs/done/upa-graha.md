# උපග්‍රහයන්

- All upgraha should show in the birth chart as
    - ධූම (Dhūma) as D
    - ව්‍යාතීපාත (Vyatipāta) as V
    - පරිවේෂ (Pariveṣa) as P
    - ඉන්ද්‍රචාප (Indrachāpa) as I
    - උපකේතු (Upaketu) as U

- The houses table should have a new column for this. It should show the upgraha in relavent house with the degree as ධූම (21:22:12) etc...

### How to calculate

මෙම ශ්ලෝක 61–64 මඟින් පරාශර මුණිවරයා විස්තර කරන්නේ **ධූම (Dhūma), ව්‍යාතීපාත (Vyatipāta), පරිවේෂ (Pariveṣa), ඉන්ද්‍රචාප (Indrachāpa) සහ උපකේතු (Upaketu)** යන උපග්‍රහ (Upagraha) පහේ දේශාංශ ගණනය කරන ආකාරයයි.

මෙය රවිගේ (Sun) දේශාංශය පදනම් කරගෙන පියවරෙන් පියවර ගණනය කරමු.

## **1. උදාහරණය සඳහා රවිගේ පිහිටීම**

අපි උපකල්පනය කරමු ජන්ම කේන්ද්‍රයක රවි පිහිටා ඇත්තේ:

උදාහරණය

| විස්තරය | අගය           |
| ------- | ------------- |
| රාශිය   | වෘෂභ (Taurus) |
| අංශක    | 15°           |
| කලා     | 20′           |

එනම් රවිගේ දේශාංශය:

\\[ 30^\circ+15^\circ20'=45^\circ20' \\]

මෙහිදී මේෂ රාශිය 0° සිට ආරම්භ වන නිසා වෘෂභ 15°20′ යනු මුළු රාශි චක්‍රයේ 45°20′ වේ.

## **2. ශ්ලෝක 61 – ධූම (Dhūma) ගණනය**

රවිගේ දේශාංශයට රාශි 4ක් සහ අංශක 13°20′ එකතු කළ යුතුය.

රාශි 4ක්:

\\[ 4\times30^\circ=120^\circ \\]

එබැවින් එකතු කළ යුතු ප්‍රමාණය:

\\[ 120^\circ+13^\circ20'=133^\circ20' \\]

දැන් රවිගේ දේශාංශයට එය එකතු කරමු.

\\[ 45^\circ20'+133^\circ20' \\]

\\[ =178^\circ40' \\]

178°40′ යනු කන්‍යා රාශියේ 28°40′ වේ.

**ධූමගේ අවසාන පිහිටීම**

# **කන්‍යා 28°40′**

Virgo 28°40′ · 178°40′

## **3. ශ්ලෝක 62 – ව්‍යාතීපාත (Vyatipāta) ගණනය**

ධූමගේ දේශාංශය 360° චක්‍රයෙන් අඩු කළ යුතුය.

\\[ Vyatipata=360^\circ-Dhuma \\]

\\[ =360^\circ-178^\circ40' \\]

\\[ =181^\circ20' \\]

181°20′ යනු තුලා රාශියේ 1°20′ වේ.

**ව්‍යාතීපාතගේ පිහිටීම:**

තුලා 1°20′

## **4. ශ්ලෝක 62 – පරිවේෂ (Pariveṣa) ගණනය**

ව්‍යාතීපාතයට රාශි 6ක් (180°) එකතු කළ යුතුය.

\\[ Parivesha=Vyatipata+180^\circ \\]

\\[ =181^\circ20'+180^\circ \\]

\\[ =361^\circ20' \\]

360° ඉක්මවා ඇති නිසා 360° අඩු කරමු.

\\[ =1^\circ20' \\]

එනම් මේෂ රාශියේ 1°20′.

**පරිවේෂගේ පිහිටීම:**

මේෂ 1°20′

## **5. ශ්ලෝක 63 – ඉන්ද්‍රචාප (Indrachāpa) ගණනය**

360° චක්‍රයෙන් පරිවේෂ අඩු කළ යුතුය.

\\[ Indrachapa=360^\circ-Parivesha \\]

\\[ =360^\circ-1^\circ20' \\]

\\[ =358^\circ40' \\]

358°40′ යනු මීන රාශියේ 28°40′ වේ.

**ඉන්ද්‍රචාපගේ පිහිටීම:**

මීන 28°40′

## **6. ශ්ලෝක 63 – උපකේතු (Upaketu) ගණනය**

ඉන්ද්‍රචාපයට 16°40′ එකතු කළ යුතුය.

\\[ Upaketu=Indrachapa+16^\circ40' \\]

\\[ =358^\circ40'+16^\circ40' \\]

\\[ =375^\circ20' \\]

360° අඩු කළ විට:

\\[ =15^\circ20' \\]

එනම් මේෂ රාශියේ 15°20′ වේ.

**උපකේතුගේ පිහිටීම:**

මේෂ 15°20′

## **7. ශ්ලෝක 64 – උපකේතු සහ රවි අතර සම්බන්ධය**

මෙහිදී සඳහන් කරන්නේ උපකේතුට එක් රාශියක් (30°) එකතු කළ විට නැවත රවිගේ මුල් දේශාංශය ලැබෙන බවයි.

\\[ Upaketu+30^\circ \\]

\\[ =15^\circ20'+30^\circ \\]

\\[ =45^\circ20' \\]

45°20′ යනු වෘෂභ රාශියේ 15°20′ වේ.

එය අප මුලින් ලබාගත් රවිගේ පිහිටීමම වේ.

**ශ්ලෝක 64 මඟින් තහවුරු වන සම්බන්ධය**

## **9. Astrology App එකට වැදගත් වන ගණනය කිරීමේ නීති**

ඔබගේ ජ්‍යොතිෂ ගණනය කිරීමේ App එකට මෙය JavaScript මඟින් ක්‍රියාත්මක කිරීමේදී සියලු ගණනය කිරීම් 0°–360° අතර තබාගැනීම සුදුසුය.

```
function normalize(degree) {
  return ((degree % 360) + 360) % 360;
}

function calculateUpagrahas(sunLongitude) {
  const dhuma = normalize(sunLongitude + 133 + 20 / 60);

  const vyatipata = normalize(360 - dhuma);

  const parivesha = normalize(vyatipata + 180);

  const indrachapa = normalize(360 - parivesha);

  const upaketu = normalize(indrachapa + 16 + 40 / 60);

  return {
    dhuma,
    vyatipata,
    parivesha,
    indrachapa,
    upaketu
  };
}

// Example: Sun at Taurus 15°20'
const sunLongitude = 45 + 20 / 60;

console.log(calculateUpagrahas(sunLongitude));
```

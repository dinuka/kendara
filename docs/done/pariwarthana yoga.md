# පරිවර්තන යෝගය (Parivartana Yoga) ගණනය කරන ආකාරය

ජ්‍යොතිෂයේ පරිවර්තන යෝගය යනු ග්‍රහයන් දෙදෙනකු එකිනෙකාට අයත් රාශිවල පිහිටීම නිසා ඇතිවන යෝගයකි. ඔබගේ ජ්‍යොතිෂ යෙදුමේ AI Agent එකට මෙම යෝගය ගණනය කිරීමට නම්, පළමුව ග්‍රහයන්ගේ රාශි අධිපතිත්වය හඳුනාගෙන, පසුව ග්‍රහයන් දෙදෙනකු අතර අන්‍යෝන්‍ය රාශි හුවමාරුවක් තිබේදැයි පරීක්ෂා කළ යුතුය.

## 1. මූලික නීතිය

ග්‍රහයන් දෙදෙනකු වන \\(A\\) සහ \\(B\\) සලකමු.

- ග්‍රහයා \\(A\\), ග්‍රහයා \\(B\\) අධිපති වන රාශියේ සිටිය යුතුය.
- ග්‍රහයා \\(B\\), ග්‍රහයා \\(A\\) අධිපති වන රාශියේ සිටිය යුතුය.

මෙම කොන්දේසි දෙකම සපුරාලන්නේ නම් පරිවර්තන යෝගයක් පවතී.

උදාහරණය:

- කුජ මේෂ රාශියේ සිටී.
- සිකුරු වෘෂභ රාශියේ සිටී.

මෙය පරිවර්තන යෝගයක් නොවේ. මන්ද කුජ මේෂ රාශියේ සිටීමෙන් සිකුරුට අයත් රාශියක සිටින බවක් නොපෙන්වන බැවිනි.

නිවැරදි උදාහරණයක්:

- කුජ වෘෂභ රාශියේ සිටී.
- සිකුරු මේෂ රාශියේ සිටී.

කුජට අයත් මේෂ රාශියේ සිකුරු ද, සිකුරුට අයත් වෘෂභ රාශියේ කුජ ද සිටින බැවින් මෙය පරිවර්තන යෝගයකි.

මෙහි බුධට අයත් කන්‍යා රාශියේ ශනි ද, ශනිට අයත් කුම්භ රාශියේ බුධ ද සිටී. එබැවින් 4–9 භාව අධිපතීන් අතර පරිවර්තනයක් ඇතිවේ.

## 4. AI Agent එක සඳහා ක්‍රියාත්මක කිරීමේ පියවර

1. ජන්ම කේන්දරයේ ලග්නය සහ ග්‍රහයන් හත්දෙනාගේ රාශි පිහිටීම් ලබාගන්න.
2. එක් එක් ග්‍රහයා අධිපති වන රාශි දෙක හඳුනාගන්න.
3. ග්‍රහයන් දෙදෙනාගේ සෑම යුගලයක්ම පරීක්ෂා කරන්න.
4. ග්‍රහයා A සිටින රාශිය ග්‍රහයා B අධිපති වන රාශියක්දැයි බලන්න.
5. එසේම ග්‍රහයා B සිටින රාශිය ග්‍රහයා A අධිපති වන රාශියක්දැයි පරීක්ෂා කරන්න.
6. කොන්දේසි දෙකම සත්‍ය නම් පරිවර්තනය හඳුනාගෙන, එයට අදාළ භාව දෙක සහ ඒවායේ අධිපතීන් වාර්තා කරන්න.
7. භාව දෙක 6, 8, 12 හෝ 3 සමඟ සම්බන්ධදැයි බලා පරිවර්තන වර්ගය තීරණය කරන්න.

### Pseudocode

```
for each unique pair of planets (A, B):
    signA = signOccupiedBy(A)
    signB = signOccupiedBy(B)

    if signA is ruled by B
       AND signB is ruled by A:

        houseA = houseOwnedBy(A, signA, ascendant)
        houseB = houseOwnedBy(B, signB, ascendant)

        if houseA or houseB is in [6, 8, 12]:
            type = "Dainya Parivartana"
        else if houseA or houseB is 3
                or houseA or houseB is 3:
            type = "Khala Parivartana"
        else:
            type = "Maha Parivartana"

        report(A, B, houseA, houseB, type)
```

වැදගත්: මෙහි `houseA` සහ `houseB` ලෙස ගණනය කළ යුත්තේ හුවමාරුවට අදාළ රාශිවල භාව අංකයි. ග්‍රහයන් භෞතිකව සිටින භාව දෙක පමණක් භාවිත නොකරන්න. ඒ දෙක වෙනස් විය හැකිය. ඉහත pseudocode එකේ Khala කොන්දේසිය ක්‍රියාත්මක කිරීමේදී 6, 8, 12 භාව සඳහා ප්‍රමුඛතාව ලබාදී, ඉන්පසු 3 වන භාවය පරීක්ෂා කිරීම ප්‍රමාණවත්ය.

# ගණ්ඩාන්ත හා ගණ්ඩමූල

If some planet in the 1st pada of Aswida, Ma, Mula such planets can mark as ගණ්ඩමූල.
If some planet in the 4th pada of Aslisha, Deta, Revathi such planets can mark as ගණ්ඩාන්ත.

As example - 1989-09-26 14:50 | District General Hospital Chilaw

Here the moon in the මා nakshathra and 1st pada. So the moon is a Gandamuula plant.
Here the Kethu in the අස්ලිස nakshathra and 4th pada. So the kethu is a Gandantha plant.

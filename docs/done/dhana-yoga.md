- Need to check langa, Chandra lagna, Suriya Lagna for this.
- Need to mentioned all reasons for the Dhana yoga. If it has more than 5 reason should mark the tag as dark green
- Such dark green tag label should change as ප්‍රබල ධන යෝග then it should possible to search

## From Dhanasthana

- If 2, 11, 5, 9 houses owners in their own house or in the other Dhanasthana houses
- If 2, 11, 5, 9 houses owners has  relationship (යෝග වීම, පරිවර්තනය වීම, දෘෂ්ඨිමය වශයෙන් දෙදෙනාම සම්බන්ද වීම) then he has Dhana yoga.

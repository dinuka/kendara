# තිති

- Horoscope should show the thithi of the Moon.
- It should show with the Nakshathra section in the calculation tab.
- It should show thithi name and number. As example අව දසවක (25), පුර පසලොස්වක(15), etc...
- For horoscopes with birth time and location it should calculated.
- For manual calculated horoscopes it should calculate with Ravi and Chandra location.
  - If sandu with Ravi - අව තුදුස්වක(29), අමාවක(30), පුර පෑලවිය(1)
  - If sandu in next Rashi of Ravi - 2, 3, 4
  - If Sandu after 2nd Rashi of Ravi - 4, 5, 6
  ....

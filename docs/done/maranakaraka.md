# මරණකාරක

- This should show in the planet table in Other column.
- How to calculate.
  - If Chandra in 8th house, then Chandra is Maranakaraka.
  - If Rahu in 9th house, then Rahu is Maranakaraka.
  - If Shani in 1st house, then Shani is Maranakaraka.
  - If Ravi in 5th house, then Ravi is Maranakaraka.
  - If Shukra in 6th house, then Shukra is Maranakaraka.
  - If Kuja in 7th house, then Kuja is Maranakaraka.
  - If Budha in 4th house, then Budha is Maranakaraka.
  - If Guru in 3rd house, then Guru is Maranakaraka.
- Every planet that occupies its designated house is a Maranakaraka — multiple planets can qualify at once.
- Check only the lagna (rasi) chart house positions. Never the D9 (navamsa) chart.

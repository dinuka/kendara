# මරණකාරක

- This should show in the planet table in Other column.
- How to calculate.
  - If Chandra in 8th house, then Chandra is Maranakaraka.
  - If Rahu in 9th house, then Chandra is Maranakaraka.
  - If Shani in 1th house, then Chandra is Maranakaraka.
  - If Ravi in 5th house, then Chandra is Maranakaraka.
  - If Shukra in 6th house, then Chandra is Maranakaraka.
  - If Kuja in 7th house, then Chandra is Maranakaraka.
  - If Budha in 4th house, then Chandra is Maranakaraka.
  - If Guru in 3th house, then Chandra is Maranakaraka.

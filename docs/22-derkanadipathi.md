# 22 දෙර්කාණාධිපති

- ලග්නයෙන්, සූර්‍ය ලග්නයෙන්, චන්ද්‍ර ලග්නයෙන් සෙවිය යුතුය.
- අදාල භාව ස්ඵුටය ගත යුතුය. උදාහරණයක් ලෙස චන්ද්‍රයා සිටින භාවයේ භාව මධ්‍ය ස්ඵුටයට අනුව 22 වැනි දෙර්කාණාධිපතියා සෙවිය යුතුය. චන්ද්‍රයා සිටින ස්ඵුටය භාවිතා නොකරයි.
- මෙය ග්‍රහයන්ගේ වගුවේ වෙනම පෙන්විය යුතුය.
  ලග්නයෙන් - 22 දෙර්කාණාධිපති
  චන්ද්‍ර ලග්නයෙන් - 22 දෙර්කාණාධිපති(සඳු)
  සූර්‍ය ලග්නයෙන් - 22 දෙර්කාණාධිපති(රවි)

# Student notepad

- Student should possible to add notes for each horoscope.
- A Notepad should popup and should possible to move, resize it.
- The Notepad should have tags for each house purpose.
  1 — The person
  2 — What he/she has
  3 — What he/she does
  4 — What gives him/her peace
  5 — What he/she creates and knows
  6 — What he/she must overcome
  7 — Whom he/she partners with
  8 — What transforms him/her
  9 — What guides him/her
  10 — What he/she accomplishes
  11 — What he/she gains
  12 — What he/she releases
- Only one parent tag should be possible to select. After click one it should show the sub tags. As example Self, Body, Personality, Identity, Vitality, Appearance, etc... will be the sub tags for the parent tag "1 — The person".

| House    | Sanskrit         | Main purpose / significations                                                           |
| -------- | ---------------- | --------------------------------------------------------------------------------------- |
| **1st**  | Tanu / Lagna     | Self, body, personality, identity, vitality, appearance, overall life direction         |
| **2nd**  | Dhana            | Wealth, accumulated resources, family, speech, food, values                             |
| **3rd**  | Sahaja / Bhrātṛ  | Courage, effort, skills, communication, younger siblings, initiative                    |
| **4th**  | Sukha            | Mother, home, property, emotional happiness, education, vehicles, inner peace           |
| **5th**  | Putra            | Intelligence, children, creativity, learning, past-life merit (Pūrva Puṇya), mantra     |
| **6th**  | Ari / Ṣaṭru      | Enemies, disease, debts, service, competition, obstacles, litigation                    |
| **7th**  | Yuvati / Kalatra | Marriage, spouse, partnerships, sexuality, business partnerships, public dealings       |
| **8th**  | Randhra / Ayu    | Longevity, transformation, death, inheritance, secrets, occult knowledge, sudden events |
| **9th**  | Dharma / Bhāgya  | Dharma, fortune, father, guru, higher knowledge, pilgrimage, blessings                  |
| **10th** | Karma            | Career, profession, status, authority, achievements, actions in the world               |
| **11th** | Lābha            | Gains, income, fulfillment of desires, elder siblings, networks, large organizations    |
| **12th** | Vyaya / Mokṣa    | Expenditure, loss, foreign places, isolation, sleep, spiritual liberation, letting go   |

- When select a sub tag, then system should show the observations of the horoscope.
  - The planets and details of each planets in the house
  - House load and its details.
  - The planet and details for the relevant sab tag.
    - ☉ Sun (Ravi) → Self, soul, father, authority, government, status
    - ☽ Moon (Chandra) → Mind, mother, emotions, happiness, nourishment
    - ♂ Mars (Kuja) → Courage, strength, younger siblings, land, competition
    - ☿ Mercury (Budha) → Intelligence, speech, communication, business, calculation
    - ♃ Jupiter (Guru) → Wisdom, guru, children, wealth, dharma, higher knowledge
    - ♀ Venus (Shukra) → Marriage, spouse, love, relationships, pleasures, vehicles
    - ♄ Saturn (Shani) → Work, service, labor, suffering, delays, longevity
    - ☊ Rahu → Foreign matters, obsession, unconventional things, material desires
    - ☋ Ketu → Detachment, spirituality, Moksha, occult knowledge, separation
  - planet details should show as the tags with colores. If some strength is good then it show in the green tag. If something is bad it showing in the red tags. others should show as white tags.

- Based on the system observations the students also can add his observations as tag. He should possible to select the color for his tag.
- Then based on all observations student should possible to add result notes.
- Also should have a another tag as other. Then student can add common notes.

# වර්ගෝත්තම

If some horoscope's Ascendant sign is equal to its navansaka sign then that horoscope is Wargoththama. So it should show in the calculation details with Ascendant (Lagna) section.
If some planet's birth chart sign is equal to its navansaka sign then that planet is Wargoththama. So that should mentioned in the other column in the planet table.

As example - 1987-04-24 23:57 | Sri Jayawardenepura General Hospital

This hosroscope Ascendant (Lagna) is Capricorn and Navansaka also Capricorn. Then that horoscope is Wargothama.
This horoscope's Mercury is in Meena sign and its Navansaka also Meena. Then Mercury is the Waroththama.

If some planet is Wargoththama but, is it Gandantha or Gandamula then Wargoththaama should show as strikethrough text.
